# Network Mastery Lab

Hands-on networking portfolio: 12 weeks of labs, packet captures, troubleshooting tickets and a capstone small-business network, built on top of CompTIA Network+ certification.

## What's inside

- **Packet Tracer labs** — VLANs, trunking, OSPF, NAT/PAT, ACLs, HSRP, IPv6 dual stack
- **Wireshark analysis** — annotated captures of TCP, DHCP, DNS and ICMP traffic
- **Services** — DHCP, DNS zones, syslog, pfSense firewall in VirtualBox
- **Troubleshooting** — help desk–style tickets using the CompTIA 7-step method
- **Capstone** — a fully documented small-business network (Weeks 11–12)
